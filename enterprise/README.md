# 🏢 Nexo Hub Enterprise Edition

Welcome to the **Nexo Hub Enterprise Edition** module.

This directory contains proprietary enterprise extensions designed for Banks, Financial Institutions, and Regulated Enterprises deploying autonomous AI Agents under strict regulatory oversight (such as CMN 5.274 / BACEN 538/2025, LGPD, and ISO 42001).

---

## ⚡ Enterprise Modules

### 1. NSEP (Nexo Secure Execution Protocol)
- **Token Context Reduction:** Up to 90% savings vs. raw OpenAPI tool-calling by executing typed scripts inside a pure-Go sandboxed runtime (`goja`).
- **Granular Audit Correlation:** Unifies multiple internal tool calls under a single `execution_id` for compliance auditors.

### 2. Automated PDF Compliance Reporting
- Single-click automated generation of BACEN/LGPD audit evidence PDFs ready for regulatory submission.

### 3. SSO & Enterprise Identity
- Enterprise SAML 2.0 / OIDC integrations with Microsoft Entra ID, Okta, and Keycloak for non-human identity governance.
